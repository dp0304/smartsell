# Analytics workspace actions

Use the shared command endpoint with `module=analytics`. The action listings reflect the active workspace role. Load sensitive records through the matching query command so it can enforce role and ingest source permissions. The period convention is `[from,to)` in the requested IANA time zone. Amounts with suffix `_minor` are integer minor units in the displayed currency.

| Feature | Commands and input fields | Resource kinds and display fields |
|---|---|---|
| AN01 metric dictionary and quality | `metric_definitions_get` (`keys?`), `revise_metric_definition` (`key`, `expected_revision`, `scope`, `unit`, `value_kind`, `subject_types`, `additivity`, `text`, `display_name`, optional native platform/name and ratio component keys), `record_observations` (`observations[]`) | `metric_definition`, `metric_definition_revision`, `metric_observation`. Show native name, revision, definition text, additivity, source, observation time, coverage, and ingest gaps. |
| AN02 social performance | `metrics_query`, `posts_performance_get` (`MetricQuery`, optional `data_cutoff_at`). `post_history` (`subject_id`, optional `data_cutoff_at`). | Display `rows[].group`, `rows[].values[key]`, `coverage`, `evidence`, `warnings`, and optional `comparison`. Evidence carries source record references, method, age deviation, and observation timestamp. |
| AN03 link metrics | `metrics_query` with subject type `short_link` and keys `link.redirects`, `link.clicks_filtered` | Reads `traffic.short_link` and `traffic.click_event`. Present total redirects and filtered clicks as separate metrics. |
| AN04 attribution | `record_attribution_evidence` (`order_id`, `subject_type`, `subject_id`, `occurred_at`, `source_ref`, `evidence_kind`, optional platform-reported `reported_amount_minor` and `currency`), `revise_attribution_model` (`model_key`, `expected_revision`, `window_days`), `attribution_run`, `attribution_query` (`period`, `model_keys?`, `store_ids?`, `report_currency?`, `subject_ids?` for query only), `attribution_explain` (`order_id`, `model_keys?`) | `attribution_evidence`, `attribution_model`, `attribution_run`, `attribution_record`, `attribution_touch`. | AN06 estimated contribution | `import_unit_costs` (`rows[]` with `product_variant_id`, `cost_minor`, `currency`, `valid_from`, `source`, `source_ref`), `record_contribution_cost` (`scope`, `item`, `period`, `currency`, `settlement_id`, `amount_minor`, `complete`), `contribution_query` (`scope`, `period`, `currency`, `store_ids?`, `data_cutoff_at?`) | `unit_cost_version`, `contribution_input`. | AN07 cohorts | `cohorts_list` (`period`, `store_ids?`, `observation_days?`, `data_cutoff_at?`) | Show first-seen counts, verified new-customer counts, the history start, excluded providers, unidentified orders, and repeat rate only after the full observation window. |
| AN08 experiments | `experiments_create` (`type`, `hypothesis`, `primary_metric`, `success_criteria`, `period`, `variants[]` with `ref_type`, `ref_id`, `allocation_bps`, `stop_conditions?`), `experiments_list`, `experiments_transition` (`experiment_id`, `expected_version`, `action`, `reason` for stop, `decision`, `limitations`, `results[]` for conclude) | `experiment`, `experiment_variant`, `experiment_result_snapshot`. Actions follow `draft` → `running` → `stopped` or `concluded` → `archived`. Results record `ref_id`, `sample_size`, `value`, `source_ref`. | AN10 audience | `record_audience_insight` (`social_account_id`, `dimension`, `source`, `source_ref`, `values`, `unit`, `observed_at?`), `audience_insights` (`social_account_id`), `posting_time_suggest` (`social_account_id`, `content_type`, `period`) | `audience_insight_snapshot`, `posting_time_recommendation`. Show sources separately. Show sample size, basis period, and limitations beside recommendations. Use a manual slot when sample size is insufficient. |

`MetricQuery` takes `metrics[]`, `subject: {type, filter?}`, and `time: {from,to,tz,basis}`. It accepts `granularity`, `age_bucket`, `group_by`, `compare`, `traffic_source`, `include_estimates`, and `report_currency`. Use `value: null` for an unknown cell. A real zero has `value: 0` and an applicable availability. Show `original_minor` and `missing_fx` when conversion is unavailable. Observation inputs carry metric key, subject type and ID, available value, source method, and optional dimensions, currency, periods and observation/publication timestamps.

Report sections have `key`, `type`, `source` (`metrics`, `revenue` or `attribution`), and a `query` for the corresponding command. They inherit report period and apply scope filters. Reports generate synchronously in the command transaction. Only draft narratives can be edited. Finalizing a newer draft supersedes the previous final version. CSV preserves Unicode. The PDF export uses an ASCII Helvetica text rendering. `reports_export` returns the file inline, with PDF encoded as base64.

Revenue and attribution are restricted to workspace owners, admins, and editors. The metric dictionary and social reads are available to readers. Admins and owners maintain FX and definitions. Owners, admins, and reviewers can finalize and export social reports. Financial reports require financial read access in addition to approval or export authority. Ingest sources must permit `display` for reads and `export` for exports.
