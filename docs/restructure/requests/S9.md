### S1 (`docs/hub-setup.md`, root scripts)

9. Add this section to `docs/hub-setup.md` (Windows installer, §8.18, §12.3 item 8):

   > **Windows 安裝包（在 Win-C 建置一次）**
   > 1. 在 Win-C 以系統管理員開啟 PowerShell，安裝：`winget install --id Git.Git -e`、`winget install --id OpenJS.NodeJS -e --version 24.*`，重新開啟 PowerShell 後 `corepack enable`。
   > 2. `git clone <repo> smartsell`、`cd smartsell`、`pnpm install --frozen-lockfile`。
   > 3. `pnpm worker:release --win`：產生 `dist\worker-release\SmartSell-Worker-<version>-win-x64.exe` 與 `latest-win-x64.json`（未簽章 NSIS，每位使用者安裝，不需要系統管理員）。第一次會下載對應版本的 Electron。
   > 4. 把這兩個檔案複製到中樞的 `<hubDir>\worker-downloads\`（例如 `tailscale file cp dist\worker-release\* <hub>:`，再在中樞把它們搬進該資料夾）。中樞的「開始設定 → 下載 SmartSell Worker」就會列出 win-x64。
   > 5. 在 Win-C 執行安裝程式：SmartScreen 顯示「Windows 已保護您的電腦」時按「其他資訊」→「仍要執行」。安裝完成後 SmartSell Worker 會自動開啟。
   > 6. 驗收（M1）：配對並命名、機器頁顯示在線與 posture 警告、重開機後自動上線。
   >
   > **macOS 安裝包**：在 Mac 上執行 `pnpm worker:release`（arm64 與 x64 的 dmg + zip）。第一次開啟：在「應用程式」對 SmartSell Worker 按右鍵 →「打開」。更新後第一次啟動若出現鑰匙圈提示，按「永遠允許」，否則 Worker 無法連線。舊版 SmartSell Connector 的配對不會帶過來，要重新配對。
   > 失敗處理：`Electron … differs from the pinned …` → 不要加 `--allow-electron-version`（那只給離線的本機驗證）；`Pinned Electron runtime is missing` 或下載失敗 → 檢查網路後重跑。
