# SmartSell 开发历程

SmartSell 是一个支持自部署的社群电商运营工作台。

## 2026-11-19 · 产品设计

整理商品、内容发布与运营工作流，形成第一份系统设计方案。

## 2026-11-20 · 从工作台到本地 Agent

首版工作台实现后，团队审查了界面和操作流程，随后调整了日常使用方式。运营人员可以通过本地 Agent 提交操作，在 Web 看板查看进展、处理审批。原有工作台保留为备用入口。

## 2026-11-21 · 三语文档与 Compose 发布

增加英文、简体中文与繁体中文 README 和图解手册，补充界面语言切换说明。简体中文覆盖 Web 看板、高级工作台、桌面连接器、客户门户与公开页面。界面切换保留用户名、工作区名称、业务内容与协议字段。

将电子表格报告运行时使用的 `yazl` 移到服务器生产依赖。用独立的 Compose 项目、全新 PostgreSQL 数据卷和回环 TLS 代理验证了 Commands 部署及 Operations 叠加配置。

连接器与快照脚本支持通过 `SMARTSELL_CLI_LANGUAGE` 切换帮助和部分操作提示。连接器 JSON 输出、退出状态及底层诊断保留原样。

桌面连接器在复制界面文件前创建 `dist/ui`，使没有构建缓存的全新检出也能完成构建。
