# 本地跨模組驗收

在 repo 根目錄使用 Node 24 與已安裝的鎖定依賴。

```sh
pnpm requirements
node --import tsx --test tests/acceptance/flows.test.mjs
bash tests/acceptance/with-postgres.sh
```

第一個命令比對兩份原稿與生成文件。第二個命令執行應用測試。第三個命令使用本機 Docker 已有的 `postgres:17-alpine`、獨立 loopback 埠和暫存資料庫，執行遷移後驗證公開分享。可用 `--test-name-pattern='^A02 '` 選跑一個情境。Node 的 TODO 仍會執行並印出斷言失敗，放行判定須以本文與矩陣列出的結果為準。

主鏈測試以 Fastify `inject` 呼叫實際 setup、命令、公開路由與 MCP HTTP 路由，使用記憶體、暫存檔或隔離的本機 PostgreSQL。測試時鐘固定，付諸發布的供應商適配器為本地 fixture，`fetch` 預設拋錯。需要平台審核、核准 scope、法務定稿、測試帳號或客戶實體手機的項目，由外部驗證清單記錄。 [分期與外部驗證](gates.md)

### A01

**內容修訂→審批→重新排期。** 建立並送審草稿，驗證送審人不能自審。提交新版本後，過時寫入回 409。恢復舊稿會新增修訂，排期改綁新修訂後原批准失效，入列回 409。審批成功步驟由同一持久化命令執行，審核人角色由 fixture 提供。待補 MCP 草稿寫入與 Web UI 的交替操作。 [CO07](../../plan.md#L4123) · [PL05](../../plan.md#L4924) · [9.4 #2](../../plan.md#L10445)

### A02

**先提交、後失去回執。** 透過帳號、內容、排期與執行的命令建任務，呼叫正式 worker，注入提交後丟失回執。日曆保留未知，首次查證未取得結果，人工接管被拒。再次派送不增加提交次數。找到已存在的作品後，依原請求與原目標關聯作品。待補真實平台、TikTok 手機草稿、跨設備路徑和多渠道查證。 [EX05](../../plan.md#L5506) · [9.4 #4](../../plan.md#L10447)

### A03

**來源採集→分析。** 寫入來源批次、完成同步並查詢指標，檢查零、未採集、無權限、來源未提供及覆蓋率。fixture 提供來源可用狀態，待補實際平台撤銷 scope、欄位映射版本與圖表呈現。 [DS06](../../plan.md#L2773) · [AN01](../../plan.md#L7303) · [9.4 #6](../../plan.md#L10449)

### A04

**Amazon CSV→匯入批次→交易分析。** 注入合成買家欄位，在提交前檢查預覽與持久化批次，提交後檢查訂單、退款與分析資料，並驗證退款覆蓋不足維持 `null`。待補 SP-API／通知入口、所有持久化載體、日常清除、歸因與佣金。 [PC01](../../plan.md#L3212) · [AN05](../../plan.md#L7307) · [9.4 #16](../../plan.md#L10459) · [V0 #53](../../plan.md#L9191)

### A05

**交付物→公開分享→撤銷。** 由工作區命令公開交付、預覽並建立分享，再經實際 portal 路由簽發 token。匿名讀取驗證公開內容、遮罩與 `no-store`，撤銷後重用原 token 回 404。需本機 PostgreSQL。待補未分享物件的完整搜尋、下載、報告查詢矩陣及桌面 UI。 [TE03](../../plan.md#L8042) · [TE04](../../plan.md#L8043) · [分享路由原文](../../plan.md#L7969)

### A06

**Operation 入口的 REST／MCP 共用資料與權限。** 同一服務及暫存檔內建立兩個租戶，第二租戶由 fixture 建立。租戶登入、PAT 簽發與撤銷、工具發現與呼叫使用 HTTP 路由。驗證精確讀寫工具列表、拒絕唯讀 PAT 寫入、跨租戶寫入與物件讀取被拒、有效寫入可查、撤銷立即生效。待補 OAuth、品牌級範圍、PostgreSQL RLS、既有 MCP 工作階段及正式部署配置。 [AI02](../../plan.md#L7798) · [TE01](../../plan.md#L8040)

### A07

**應用啟動冒煙。** 確認 19 個模組可被 `discover()` 載入。這一項只驗證註冊，無需求行引用此項作業務證據。

### A08

**預設 Command 服務的 MCP 接線。** 斷言 `/mcp` 未帶憑證時回 401 與 Bearer challenge。現況回 404，測試保留為 TODO。A06 的 Operation 服務掛載 `/mcp`。 [Command 入口](../../apps/server/src/bootstrap.ts#L31) · [Operation 入口](../../apps/server/src/server.ts#L114)
