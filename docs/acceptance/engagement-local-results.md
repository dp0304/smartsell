## 重跑

使用 Node 24.21.0。最後一輪 Node 核心 HTTP 和領域組 72 通過、0 失敗、1 跳過。跳過的是未配置連線的 PostgreSQL public scope。Vitest 的收件箱命令組另有 3 項通過。各 Chromium 規格使用獨立輸出目錄，公開表單與簽名分享 2 項通過，收件箱、達人和具名門戶各 1 項通過。收件箱前兩次因混用命令及 Operations 入口失敗，改用 Operations 宿主和 REST 回覆後通過。另一次桌面瀏覽器矩陣中，系統 Chrome 通過，WebKit、Firefox 和 Edge 在啟動或建立頁面階段失敗。

export PATH="$HOME/.nvm/versions/node/v24.21.0/bin:$PATH"
