## 独立服务与兼容结果

- PostgreSQL 17 从旧迁移 111 升级到 112、113，使用老邮箱密码及旧会话重新读取。账号、owner 权限、工作区以及 Commands 和 Operations 的业务记录 ID 与版本均保留。再次迁移未增记录。 [旧身份迁移回归](../../apps/server/src/integration/legacy-identity-upgrade.test.ts)
- 正式 Compose 源和恢复目标分别下载同一签名素材，SHA-256 均为 `160c5192dcffafdfc73d04c2e69a43b051e7d61b9074bbfb0368b34881bb42d5`。原不确定发布尝试只增加人工核验结果，尝试次数不变。 [正式恢复脚本](../../infra/ops-compose-smoke.sh)
- 在本地桌面读表与签名上传入口接受 5,000 行且恰为 384 KiB 的 UTF-8 CSV。分别超过行数或字节上限被拒绝，未形成导入批次。该边界覆盖文件存储与 CSV。 [商品表边界回归](../../apps/server/src/modules/commerce/worker-catalog.test.ts)
- macOS 14.5 上，Playwright WebKit 26.0（2215）在总览直接续办通过。注册、跳过 Agent、进入 Worker、刷新 Worker 页、暂离向导到总览，再刷新时两次崩溃。WebContent 在导航提交阶段终止。纯 HTML 对照通过，新版 WebKit 2251 因该系统上不支持 `PushAPIEnabled` 而未进入测试，具体触发因素仍待定位。原生 Safari、正式发布版 Firefox 和 Windows 尚待独立实测。
