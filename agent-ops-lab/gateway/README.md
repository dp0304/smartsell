## 复跑

需要 Node 24、FFmpeg 和隔离源码副本现有依赖。默认源码路径为 `../../.local/mcp-lab-Lh53qf`，可通过 `SMARTSELL_SOURCE` 指定含新版审计 API 的副本。默认使用回环临时端口，可用 `LAB_API_PORT`、`LAB_WEB_PORT` 覆盖。

```sh
cd agent-ops-lab/gateway
SMARTSELL_SOURCE="$(cd ../.. && pwd)" node run.mjs
node verify.mjs runs/2026-11-21T17-17-55.849Z-12aee117
```

复跑时用程序打印的新目录替换验证参数。`node run.mjs --priority-only` 只跑优先场景。每次新建 SQLite、媒体目录和合成账号，结束后撤销 Agent 连接并关停服务。`runtime/` 为未纳入版本跟踪的本地运行数据。报告、脚本和证据均在 `gateway/`。
